# Copilot Instructions for game-pronounce

## Deployment Rules

### Cloudflare Preview for Staging PR Work
Always use Cloudflare preview environments (`wrangler deploy --dry-run` or preview deployments) for staging pull request work before deploying to production (`pronounce.alldem.app`). Do not deploy directly to production without first validating changes in a preview environment.

### Production Deployment Guardrails
- Never run `npm run deploy` (which deploys to `pronounce.alldem.app`) directly from a feature branch without prior preview validation.
- Use `wrangler dev` for local development testing.
- Use `wrangler deploy --dry-run` to validate configuration before production deployment.
- Production deployments should only occur from the `main` branch via the GitHub Actions workflow (`.github/workflows/deploy-to-cloudflare.yml`).

## Project Context
- This is a pronunciation game deployed as a Cloudflare Worker with static assets.
- D1 database: `pronounce-results` (speech recognition logging)
- Custom domain: `pronounce.alldem.app`
- Debug logging is opt-in via `?debugMic=1` or `localStorage.setItem("pronounce.debugMic", "1")`
- Admin dashboard API is protected by `ADMIN_TOKEN` secret
